# CodeAlpha_StockPortfolio

A simple Stock Portfolio Tracker developed in Python as part of the CodeAlpha Python Programming Internship.

## Features

- Accepts stock symbols from the user
- Accepts the quantity of shares
- Uses predefined stock prices
- Calculates the investment value
- Calculates total investment
- Handles invalid stock symbols
- Handles invalid quantities
- Saves the final result to a text file

## Stocks Included

- AAPL
- TSLA
- GOOGL
- MSFT
- AMZN

## Technologies Used

- Python
- Dictionary
- User input
- Conditional statements
- Loops
- Basic arithmetic
- File handling

## How to Run

1. Make sure Python is installed.
2. Download or clone this repository.
3. Open the project folder in VS Code or terminal.
4. Run:

python portfolio.py
